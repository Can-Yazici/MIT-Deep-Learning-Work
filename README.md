## 📌 About

The content in this repository is primarily based on official MIT course resources.

This is **not an original project**, but a collection of my solutions and understanding of the course topics.

## 📂 Structure

Each folder corresponds to a specific assignment or lab:

- `assignment1/` – Solutions and answers for the first lab
- `assignment2/` – Follow-up exercises and implementations
- `...`

Within each folder, you may find:
- Jupyter notebooks (`.ipynb`) with completed code and explanations
- Python scripts (`.py`) for cleaner implementations (if applicable)
- Notes or comments explaining key concepts
